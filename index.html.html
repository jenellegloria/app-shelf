Setup Guide
1. Create a free Cloudflare account
2. Go to Workers & Pages → Create Worker
3. Paste the appshelf-worker.js code
4. Go to KV → Create namespace → name it APPSHELF_KV
5. In your Worker settings → Variables → KV Bindings → add APPSHELF_KV
6. Copy your Worker URL and paste it above
