SETUP GUIDE
1. Free account at cloudflare.com
2. Workers & Pages → Create application → Start with Hello World → Deploy
3. Edit code → paste appshelf-worker.js → Deploy again
4. KV (sidebar) → Create namespace → name it APPSHELF_KV
5. Your Worker → Bindings → Add → KV Namespace → variable: APPSHELF_KV
6. Copy your Worker URL and paste above
